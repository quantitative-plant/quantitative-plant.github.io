Toaster is an ImageJ's plugin, which manages different tools developed by Amap teams (http://amap.cirad.fr) for the identification and geometrical characterization of anatomical structures from macro to microscopic images. Toaster can be seen as an integrated super-plugin of ImageJ software. It gathers all the specialized plugins developed in our laboratory and allows managing the user configurations.

However each plugin can be separately downloaded and installed.

Several tools are already available:

- Celer
- Cefiler
- Leaver
