Leaver is a fully-automated plugin devoted to the analysis of homogeneous leaves geometry in digitized images produced by desktop scanners. This tool answers a particular need that is to organize naturally results to allow the data matching in great-scale analysis. The numerical results (area, length, width, circularity,…) are given in csv files, easily readable on spreadsheet.

## Notes

Leaver is part of the Toaster ImageJ plugin
