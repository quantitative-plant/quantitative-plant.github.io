LIMANI (Leaf Image Analysis Interface) is an on-line framework for the analysis of vascular networks in leaves. It allows for the automatic segmentation and measurement of venation patterns of cleared leaf images captured by dark-field microscopy. The framework also includes an interactive and user-friendly interface providing the possibility for manual segmentation corrections for high precision analysis.
