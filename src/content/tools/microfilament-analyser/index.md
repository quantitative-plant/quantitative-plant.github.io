MicroFilament Analyzer is a software that allows the quantified analysis of microtubules or actin microfilaments. More specifically, we use it to study the cytoskeletal organisation of transgenic GFP leaves and root cells of Arabidopsis thaliana. The program might however be useful in broader fields as well.

## Notes

Requires MatLab to run
