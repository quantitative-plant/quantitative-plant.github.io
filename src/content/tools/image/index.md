ImAGE takes images of grape canopies with a blue background and calculates the percentage of gaps in the canopy.

The software can batch process images for rapid analysis of multiple grapevines.

## Installation & usage

Images loaded into the software must be of a grapevine with a blue backdrop behind it (e.g. a blue tarpaulin).

Grapevine images should be cropped to include only the bunch line or captured so as to target the area of the canopy that is of most interest and should only include vine and backdrop (see cropping/capturing example).
