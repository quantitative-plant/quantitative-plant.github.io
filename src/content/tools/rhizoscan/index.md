RhizoScan is a solution for extracting the full root architecture automatically and on a large-scale data set. Because our framework is included in the OpenAlea platform, in addition to traditional data analysis such as the ones provided by existing software, the extracted data can also be used seamlessly as input of all the architectural analysis packages already contained in OpenAlea.

## Notes

Works only in the OpenAlea platform
