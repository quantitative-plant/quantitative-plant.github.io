LeafJ is a plugin for ImageJ that aids in the measurement of plant leafs. Compared to other leaf measurement tools LeafJ is able to determine the border between the leaf blade and petiole, and return length measurements for both. LeafJ also returns blade area, perimeter, and circularity. LeafJ was written by Julin Maloof.
