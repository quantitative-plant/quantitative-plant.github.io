The Integrated Analysis Platform IAP contains several components, crucial for the analaysis of high-throughput image data. It contains a data-access-module, which makes it possible to directly access data stored within LemnaTec databases and to load exported datasets. The system is not limited to a single data source as it contains file import functions, which make it possible to load and process data from other sources.
