PDQUANT provides an automated image processing workflow that detected and quantified plasmodesmata candidates, identified cell boundaries, and segmented immature cells from older cells. The algorithm segments and quantifies epidermal cells with differentiation of mature from young emerging cells.

## Notes

Requires Acapella to run
