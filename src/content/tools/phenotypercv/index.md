PhenotyperCV is a C++ framework that analyzes images in a high-throughput manner. It was originally developed for commercial phenotyping platforms but has developed into a broad tool that can easily be used to process small scale images. Along with measuring morphology and color, this framework includes the tools to color correct images, calibrate cameras, convert image coordinates to world coordinates, and includes machine learning functionality. PhenotyperCV is open source and any contribution from the community is very welcome.
