# About

**Quantitative Plant** (quantitative-plant.org) helps researchers find the right software, dataset or model for quantitative plant science. It started in 2013 as a list of root image analysis software (then known as *plant-image-analysis.org*) and grew into a catalogue of image analysis tools, image datasets and plant models covering every scale, from cells to fields.

## How the catalogue works

Every entry is a small Markdown file stored in a public [GitHub repository](https://github.com/quantitative-plant/quantitative-plant.org). Anyone can propose a new entry or a correction, either by opening a pull request or by filling in a short form (which creates a GitHub issue that a curator reviews). The website is rebuilt automatically after each accepted change.

Entries carry a **status**:

- **Active** — checked recently, links work.
- **Not re-checked** — inherited from the 2013–2017 catalogue, not yet reviewed.
- **Unmaintained / Deprecated** — still listed for reproducibility of older studies.

## Disclaimer

This website has no commercial purpose and does not promote any specific tool. Information and pictures come from the tools' websites, user manuals and scientific articles. If you notice a mistake or a copyright issue, please [report it](https://github.com/quantitative-plant/quantitative-plant.org/issues) or [email us](mailto:plantimageanalysis@gmail.com) and we will correct it quickly.

## Conflict of interest

The curators develop some of the listed tools and models (e.g. SmartRoot, GLO-RIA, CPlantBox). These entries follow the same template and receive the same space as all others; please tell us if you think otherwise.
