# API

All catalogue data is available as static JSON files, regenerated at every update. No key, no rate limit. Data is licensed under ODC-By 1.0.

| Endpoint | Content |
|---|---|
| [`/api/tools.json`](/api/tools.json) | all software tools |
| [`/api/datasets.json`](/api/datasets.json) | all datasets |
| [`/api/models.json`](/api/models.json) | all models |
| [`/api/all.json`](/api/all.json) | everything |
| `/api/tools/{id}.json` | one tool, e.g. [`/api/tools/dirt.json`](/api/tools/dirt.json) |

Each list has the form `{ "generated", "license", "count", "items": [...] }`.

## Examples

```bash
# All open-source root tools, with jq
curl -s https://www.quantitative-plant.org/api/tools.json \
  | jq '.items[] | select((.organs|index("root-system")) and (.license|index("open-source"))) | .title'
```

```r
# R
library(jsonlite)
tools <- fromJSON("https://www.quantitative-plant.org/api/tools.json")$items
table(unlist(tools$organs))
```

```python
# Python
import pandas as pd, requests
tools = pd.json_normalize(requests.get("https://www.quantitative-plant.org/api/tools.json").json()["items"])
```

## Migrating from the old API

The previous API (`/api?type=tool&field=organ&q=leaf`) was generated by PHP on every request. Its equivalent is now a simple filter on the static files:

| Old query | New |
|---|---|
| `type=tool` | `/api/tools.json` |
| `type=dataset` | `/api/datasets.json` |
| `type=all` | `/api/all.json` |
| `field=organ&q=leaf` | filter `items` where `organs` contains `leaf` |
| `field=measurement&q=length` | filter `items` where `measurements` contains `length` |
| `field=free&q=...` | use the [search page](/search) or filter client-side |

The raw Markdown files are also available on [GitHub](https://github.com/quantitative-plant/quantitative-plant.org/tree/main/src/content).
